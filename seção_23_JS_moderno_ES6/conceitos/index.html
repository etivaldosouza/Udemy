O que é ES6?

Lembrando que ES6 seria a razão social e JS o nome fantazia da linguagem

  • Uma Versão nova(6) de JS que trouxe diversas funcionalidades
  • São os conhecimentos base para aprender os frameworks modernos(React,Vue e etc)
  • E também agilizam muito o desenvolvimento do JS puro
  • Nesta seção vamos aprender os principais recursos de ES6!
