A Web: HTML

  1. HTML(Hyper Text Markup Language) é uma linguagem de marcação;

  2. Responsável pelos textos e elementos que vemos na tela ao acessar uma página web.

  3. As tags do HTML criam: títulos, parágrafos, imagens, listas e etc.

  4. Uma tag é definida por sinal de maior e menor

  5. obs: Algumas tags não possuem fechamento.

  6. Todo documento HTML tem duas partes importantes: head e body

  7. O head serve para configurações do documento, como links de folha de estilo ou até scripts de javascript

  8. Tags de configuração: meta,link

  9. O body para os elementos(tags), ou seja, a parte visual

  10. tags do body: p,h1,h2,div,ul,li, etc.

Porquê Marcação

a tag ''a''' marca que é um link

a tag ''p'' marca que é um parágrafo
