A Web: Protocolos

  1. Um Protocolo é uma forma de comunicação entre computadores através da rede

  2. O HTTP, serve para nós solicitarmos arquivos, imagens e etc(Hyper Text Trasnfer Protocol)

  3. Entramos em sites graças ao protocolo HTTP

  4. SMTP = protocolos para enviar e-mail

  5. TCP = protocolo de transferência dados, arquivos;

A Web: URL

  1. Cada arquivo que carrega no navegador é nomeado por uma URL

  2. A URL (Uniform Resource Locator) pode ser dividida em três partes: protocolo, servidor e arquivo

  3. http://www.horadecodar.com.br/index.html

  4. http = protocolo

  5. www.horadecodar.com.br = servidor (DNS para um IP)

  6. index.html = arquivo
